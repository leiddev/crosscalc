## v0.1.0 — 第一个版本：把计算核心接进跨平台外壳

第一个可以下载的版本。界面上是一个三模式计算器，底下是
**tinyexpr-plusplus** 做全部求值 + `webview` 提供原生窗口 +
`cpp-httplib` 提供本地服务 + `cpp-embedlib` 把前端打进可执行文件。

### 它是什么

跑起来是一个原生窗口，界面是本地 HTML 页面，但它**不是从磁盘读的**：
HTML / CSS / JS 全部被 `cpp-embedlib` 编译进了可执行文件，由后台的 `cpp-httplib`
服务器从内存里发出来，窗口由 `webview` 创建（Windows 上是 Edge WebView2，
Linux 上是 GTK + WebKitGTK）。

计算部分**没有一行是自己写的**：表达式解析、优先级、括号、函数调用、
数学运算全部交给 tinyexpr-plusplus。本项目只做三件事——模式的输入校验、
错误信息的中文化、以及结果的进制显示。

### 三种模式

- **标准**：四则运算、括号、`pi` / `e`、幂 `^`（`**` 同义）、取模。
- **科学**：三角函数 / 反三角 / 双曲 / 对数 / 阶乘 / 组合数等（**只有弧度**）。
- **程序员**：hex / dec / oct / bin 四种进制**同时显示**，
  字长 BYTE / WORD / DWORD / QWORD，以及 `BITAND` / `BITOR` / `BITXOR` /
  `BITNOT` / 移位 / 循环移位等整套按位运算。

三种模式共用同一个输入框（表达式模式），只是键盘按钮与结果面板不同。

### 值得一说的地方

- **中文的错误提示**：库有三种互不相同的失败方式（抛异常 / 静默返回错误码 /
  **静默返回 NaN**），全部归一化成一句人话，并且尽量给出出错位置与高亮区间。
  例如 `HEX2DEC("ZZ")` 在库里是"悄悄给你一个 NaN"，这里会明确说：
  参数不是合法数字，以及 `HEX2DEC("FF") = 255` 这样的正例。
- **进制换算只有一份实现**：程序员模式那四行进制结果全部由后端算好下发
  （`all_bases` 字段），前端不做任何位运算，避免前后端算法漂移。
- **QWORD(64 位字长) 在 Linux / macOS(x86-64) 上精确可用**：引擎用 80 位扩展精度的
  `long double` 作为内部类型，64 位位模式可以原样呈现。
  Windows（MSVC 的 `long double` 与 `double` 同宽）上会**明确拒绝**并说明原因，
  而不是给出被舍入的错误答案——界面上的 QWORD 按钮会置灰。
- **前端二进制/八进制输入没有走 `BIN2DEC` / `OCT2DEC`**：这两个库函数最多接受 10 位
  数字、且凑满 10 位时按有符号解释（`BIN2DEC("1111111111")` 是 −1），
  拿来做输入通道会静默出错。数字键改成按 4 位一组无损重排成 `0x` 字面量，
  QWORD 字长下也能精确输入。

### 自测

**每一个平台都必须跑完全部自测**，CI 才算绿：

| 层 | 内容 | Windows | Linux |
|---|---|---|---|
| ① 单元测试 | 45 个用例 | 通过 | 通过 |
| ① 黄金向量 | 318 条（`standard` / `scientific` / `programmer` / `errors`） | 313 条（5 条 QWORD 跳过） | **318 条，一条不跳** |
| ② HTTP 端到端 | 以 `--headless` 启动真实进程，把全部向量经 HTTP 回放 | 通过 | 通过 |
| ③ 前端 ↔ 引擎一致性 | 键盘按钮只能插入引擎真正认识的函数；DOM id、模式集合、API 契约 | 通过 | 通过 |
| ④ app.js 纯函数 | 进制重排，300 组与 BigInt 对照 | 通过 | 通过 |
| ⑤ GUI 冒烟（Xvfb） | 真的把窗口跑起来，验证 WebKitGTK 渲染链路 | —（无桌面会话） | 通过 |

编译在 GCC 11 与 MSVC 上都是 **0 警告**。

### 已知限制

- **macOS 未验证**：webview 在 macOS 上走 WKWebView，代码里也留了分支，
  但构建脚本和 CI 都没有覆盖它，所以不敢说能跑。
- **Windows 上不做 64 位字长**（原因见上）。
- **只支持弧度**，没有 DEG / GRAD。
- **`log2` / `sec` / `csc` / `asinh` / `gcd` 等不支持**：库不提供。
- **按位运算参数上限 2^48−1**：库自身的限制，超出会给出明确提示。
- **浮点结果显示最多 17 位有效数字**：两个平台保持一致；
  需要精确的 64 位数值请看程序员模式的位模式。
- **没有安装包**：产物就是单个可执行文件（前端已经在里面了），
  但 Windows 侧依赖系统的 WebView2 运行时，Linux 侧依赖系统的 WebKitGTK。
