## v0.1.1 — 让发布流程自己说明白

第一个带**手写发布说明**的版本：说明不再由 GitHub 自动生成，而是从本文件读取
（约定见 README 的「下载预编译版本」一节：`release-notes/<tag>.md` 优先，其次
根目录 `RELEASE_NOTES.md`，都没有才回退到 `--generate-notes`）。

### 本次改动

- **CI 不再报 node20 弃用告警**：`actions/upload-artifact` 升到 v6、
  `actions/download-artifact` 升到 v7，都换成了 node24 运行时（输入参数没变，
  `name` / `path` 等照旧）。
- **发布说明支持手写**：publish job 增加了 `actions/checkout`，按
  `release-notes/<tag>.md` → `RELEASE_NOTES.md` → 自动生成的顺序取正文。
- **README 新增「下载预编译版本」一节**：写清两个二进制各自需要什么才能跑起来
  （Windows 要 WebView2 运行时，Linux 要 WebKitGTK 4.1 + 显示环境），
  以及 tag 推上去之后 CI 到底做了什么。

### 下载

| 文件 | 平台 | 运行前提 |
| --- | --- | --- |
| `webview-demo-v0.1.1-windows-x64.exe` | Windows 10/11 x64 | WebView2 运行时（Win11 及较新的 Win10 一般自带） |
| `webview-demo-v0.1.1-linux-x64` | Linux x64 | WebKitGTK 4.1（`libwebkit2gtk-4.1-0`）+ 可用的显示环境 |

两个二进制都是推 tag 之后由 CI 现场从该 commit 编出来的，不是手工上传的。
