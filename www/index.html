① HTTP API

点击按钮，页面用 fetch() 请求 http://127.0.0.1:<随机端口>，由 C++（cpp-httplib）处理。

② 原生调用

这些按钮不经过 HTTP：JS 通过 webview_bind 直接调用 C++ 函数并拿到返回值（Promise）。

静态资源来自 Web::FS：httplib::mount(svr, Web::FS) 把内嵌文件挂到了 /。
